# Legacy: Inventory Manager 1.0 (business stock)

The first prototype, a standalone single-user desktop app on SQLite. It was superseded by SAIMS
(see the project README). Its theme, charts and table widgets were reused in `saims/desktop/ui`.
Kept for reference only; it is not built or tested by `build.sh`.

Run it from the project root: `cd legacy && python run.py`
